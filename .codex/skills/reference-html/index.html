这套静态页面用于给产品经理和模型提供“接近现有客户端”的结构参考。目标不是还原真实业务逻辑，而是固化桌面交易工作台的页面骨架、密度、控件尺度、状态表达和多窗口工作方式。

使用规则
  • 优先继承桌面工作台骨架，不要改造成普通网页后台或卡片流布局。
  • 高频业务页优先采用表格驱动，筛选、排序、批量操作、导入导出应作为一级能力出现。
  • 控件高度、间距、边框、状态标签和颜色语义必须继承 token。
  • 需要显式考虑加载态、断连态、只读态、空态和无权限态。
  • 允许替换业务字段和文案，不允许重构整体导航结构和信息密度。
