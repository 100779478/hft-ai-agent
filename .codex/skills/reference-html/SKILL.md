# HFT 风格参考

把项目里的 HFT 桌面 UI 风格应用到目标 HTML 页面上。

这个 skill 只管视觉语言、布局密度和组件处理方式，不负责定义业务模块、后端字段或页面数据。

如果页面需求尚未在接口文档中检索到依据，不要进入这个 skill 的样式实现阶段。

## 核心边界

- 样式参考不能成为先出静态页的理由。
- 接口文档里没有的字段，不要为了版面完整硬展示。
- 只对文档中真实存在的页面能力做样式包装。

## 一屏布局规则

- 默认按桌面工作台一屏展示设计，优先让主要信息在首屏完成操作和查看。
- 页面根容器优先使用视口高度，例如 `height: 100vh` 或等价结构。
- 页面外层优先 `overflow: hidden`，不要让整个 body 无限向下滚动。
- 表格区、详情区、日志区、侧栏等密集区域如果内容超出，应各自使用内部滚动条。
- 使用弹性布局或网格布局时，给滚动子区域设置可收缩约束，例如 `min-height: 0`、`min-width: 0`。
- 工具栏、筛选栏、状态栏保持固定占位，主内容区承担剩余空间。

## 禁止事项

- 不要把所有模块纵向堆叠到需要整页长滚动才能使用。
- 不要为了省事把数据表格撑开整个页面高度。
- 不要让首屏看不到核心操作区或核心结果区。
